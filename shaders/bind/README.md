# bind：Minecraft 输入适配

这个目录只做一件事：把加载器提供的时间、相机、天气、维度、G 缓冲与群系输入，解成普通数值或普通结构体。效果选项、效果算法、画面读写和光照判断不放在这里。

## 文件

| 文件 | 内容 |
| --- | --- |
| `camera.glsl` | 投影与视图矩阵、画面尺寸、像素大小、抖动、相机位置 |
| `time.glsl` | 累计秒数、帧时间、帧序号、世界天数、太阳角度 |
| `weather.glsl` | 降雨湿润度、眼睛亮度、夜视、失明、黑暗、脚下介质、雪与降水标记 |
| `world.glsl` | 维度编号、世界空间太阳方向、阴影光源方向与阴影矩阵 |
| `gbuffer.glsl` | G 缓冲通道解码、材质编号、掩码、粒子修正、labPBR 解码与手部判断 |
| `world/biome.glsl` | 四个群系的加载器输入与雾色、雾密度权重 |

## 用法

```glsl
#include "/bind/time.glsl"

OmniTime time = bind_time();
float seconds = time.seconds;
```

## 约定

- 只接收加载器输入，输出普通数值或只含数值与矩阵的结构体；不返回采样器，不做颜色分级、光照或雾的最终判断。
- 只允许引用 `common/`（加载器声明与坐标约定）、`omni-gfx/`（纯算法）和 `effects/`（读取输入格式选项）；不引用 `rendering/`，避免输入层反向依赖某个绘制阶段。
- 采样器与中间画面只在真正使用它们的阶段读取。需要读画面的算法放 `effects/` 的所属效果文件，纯公式放 `omni-gfx`。
- 菜单选项只定义在 `effects/`。这里只读取与“输入格式”有关的选项，例如纹理通道、PBR 格式与群系开关，不新增选项。
- 新增宿主输入时先在这里出现一次，绘制阶段再从绑定函数或结构体取值，避免同一个加载器名字散落在多个效果文件里。
- 维度分支使用入口宏 `OMNI_NETHER`、`OMNI_END`，与 `world0/`、`world1/`、`world-1/` 三个目录一一对应。

## 边界

`bind/` 是 Minecraft 专属代码，不能独立发布。`omni-gfx` 只接收这里整理出的参数，不出现加载器名字；`effects/` 按效果读取输入、调用 `omni-gfx` 并写出结果；`rendering/` 只排程序主体和阶段顺序。
