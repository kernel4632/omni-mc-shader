# bind：Minecraft 输入与效果接线

这个目录负责把加载器提供的输入接成普通参数，并保留每个效果的宿主接线：时间、相机、天气、维度、光照方向、中间画面读写和采样器都在这里出现。`shaders/gfx/` 仍然只做纯计算，不读取任何 Minecraft 名字。

## 文件

| 文件或目录 | 内容 |
| --- | --- |
| `time.glsl` | 累计秒数、帧时间、帧序号、世界天数、太阳角度 |
| `camera.glsl` | 投影与视图矩阵、画面尺寸、像素大小、抖动、相机位置 |
| `weather.glsl` | 降雨湿润度、眼睛亮度、夜视、失明、黑暗、脚下介质、雪与降水标记 |
| `world.glsl` | 维度编号、世界空间太阳方向、阴影光源方向与阴影矩阵 |
| 其它分类目录 | 与 `shaders/effects/` 同名，保存该效果的宿主接线；例如 `bind/water/waves.glsl` |

## 用法

```glsl
#include "/bind/time.glsl"

OmniTime time = bind_time();
float seconds = time.seconds;
```

## 约定

- 菜单选项只定义在 `shaders/effects/`；绑定文件用 `#include` 读取同一效果的选项，不重复声明默认值。
- 读取采样器、中间画面、`gl_*` 与宿主 uniform 的代码放这里；能独立成纯函数的计算优先放 `gfx/`，绑定层只保留参数转换。
- 通用结构体只放数值和矩阵，不放采样器、选项宏或加载器专用的名字。
- 新增宿主输入时先在这里出现一次，绘制主体再从绑定函数或结构体取值。
- 一个效果只保留一份宿主接线；三个维度共用同一入口时，用维度宏在这里分支。

## 边界

这里仍然是 Minecraft 专属代码，和 `gfx/` 可以独立发布的约定不同。`bind/` 与 `common/` 一起构成宿主层，`gfx/` 只接收这里的输出。效果层不再保存算法或中间画面读写，只保存菜单选项。
