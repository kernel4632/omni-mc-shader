# omni-gfx

与 Minecraft 无关的 GLSL 图形库，目标是可以单独复制到其他 OpenGL / Vulkan 项目使用。

## 约束

- 不读取任何 `OMNI_*` 选项、Minecraft uniform、Iris 中间画面或纹理。
- 只接收显式参数，返回纯计算结果。
- 函数名统一使用 `gfx_` 前缀，避免与宿主工程重名。
- 不在这里写 `#version`；由宿主程序决定 GLSL 版本，当前按 GLSL 330 编写。
- 不引用 `common/`、`bind/` 或 `effects/`；需要共用数学时只引用本目录内的模块。
- `tests/test_effects.py` 的通用库边界测试会检查上述限制。

## 当前模块

| 文件 | 内容 |
| --- | --- |
| `color.glsl` | 线性颜色、亮度、伽马、ACES、AgX、无压缩、黑边、浦肯野、白平衡、高级调色 |
| `math.glsl` | 曲线、重映射、编码、法线、双向反射、噪声、求交、旋转、曲率 |
| `sampling.glsl` | 蓝噪声、时序抖动、拜尔抖动 |
| `surface.glsl` | 方块光曲线、方块光与纹理自发光合成、材质遮蔽、法线缩放、矿石与纹饰发光 |
| `atmosphere.glsl` | 大气几何、密度、星场、日月圆盘、极光、彩虹、天空盒投影、行星表面 |
| `planet.glsl` | 末地行星本体、光环与大气，半径、时间、阴影与噪声贴图全部作为参数传入 |
| `parallax.glsl` | 高度图双线性采样、平滑与锐利视差、视差自阴影、由高度场生成法线 |
| `accretion.glsl` | 黑洞吸积盘积分、空间扭曲、盘着色、圆环辉光与多普勒调制 |
| `cloud.glsl` | 云的光照相位、顶部曲线、平面云噪声、扭曲、密度、光照密度、云影投影与模糊 |
| `cloud_volume.glsl` | 体积云形状、密度、光照、沿视线步进、闪电与云影 |
| `water.glsl` | 六层波高、波法线、水面视差、水洼、雨雾高光、雨点动画、水雾合成 |
| `fog.glsl` | 粉末效应、散射相位、高度雾、团雾、下界与末地雾、云状分形噪声 |
| `fog_volume.glsl` | 体积雾密度、光照吸收、步进、阴影、云影、闪电、暴风、群系与水下光柱 |
| `shadow.glsl` | 阴影相机投影、边缘压缩、读取端补压缩、屏幕空间步进、可变半影与彩色阴影 |
| `gi.glsl` | 环境遮蔽多弹射与地平线遮蔽多切片搜索 |
| `reflection.glsl` | 可见法线采样、屏幕空间追踪、反射主流程、中性合成参数、菲涅耳合并与小波滤波 |
| `voxel.glsl` | 三维逐格步进、半透明染色、铁块镜面弹射与体素着色 |
| `post.glsl` | 泛光降采样、轴向高斯、三次升采样、调色、暗角、眩光、景深、颗粒、动态模糊与自动曝光分块 |
| `antialias.glsl` | 亮度色差转换、历史裁剪、四分量三次采样 |
| `weather.glsl` | 雨雪随风偏移、植被判断、季节上色、暴风与每日天气 |

## 用法

```glsl
#include "/gfx/color.glsl"

vec3 display = gfx_agx(linearColor, 13.0, true);
```
