# 兼容性与验证

本文件区分准备目标与真实验证，不能根据下载文件名推断已经兼容。

## 当前开发目标

- Minecraft Java；初始入口使用 GLSL 330 compatibility。
- 日常开发优先使用 Iris；OptiFine 的实际加载尚未验证。
- 专用调试整合包的精确版本见 `dev-tools.lock.json`。
- 检查脚本支持 Windows / Linux x64 与 Python 3.12+。
