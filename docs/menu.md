# 菜单设计

本文件定义玩家在游戏里看到的分类、子页和参数命名。它是重写菜单与参数的依据。
配套的完整参数清单见 `parameters.md`（每个参数一行，含标识符、改什么、状态）。

## 目标

一套光影，用直观参数调出多种风格。玩家不需要懂图形学，不需要知道算法名字，
只需要看到分类就知道去哪里改，拖一下就能看到画面变化。

## 三条硬规则

1. **没有算法开关。** 云只有一套、水只有一套、影子柔化只有一套。算法选型由项目内部决定，
   玩家看不到「模式」「算法」「单层/体积/平面」这种选项。
2. **没有专业因子。** 不出现「粗糙度、菲涅耳、环境遮蔽、色调映射算子」这类词。
   改成「反光强弱、缝隙变暗、高光还原」这种人话。
3. **全都摆出来。** 质量、精度、步数也做成参数，用「精细度」「清晰度」命名，不隐藏、不加「高级」。
   所有参数都必须能在菜单里被看到一次。

## 命名规则

- 菜单显示名：中文短词，一眼懂。例：`水色红`、`云量`、`影子柔化`。
- 选项标识符：英文 `OMNI_` 前缀加含义，供代码与配置使用。例：`OMNI_WATER_RED`。
- 数值档位：能写成人话就写人话（用 `value.*` 数值标签）。例：`圆` / `六边`、`低` / `中` / `高`。
- 悬停说明：第一句讲改了会怎样，第二句给推荐值；例子只用 Minecraft 里的东西。

## 主界面

一行按钮：`预设` 加下面 15 个分类。

```
预设  天空  云  雾与空气  水  地面与植物  光照  影子
反射  画面颜色  镜头  清晰与流畅  天气与季节  生物与玩家  世界与远景  开发者
```

想改水找「水」，想改整体偏色找「画面颜色」，想改卡顿找「清晰与流畅」。

## 质量参数放哪

- 只影响单个效果的精细度（云精细度、阴影清晰度、体积精细度、反射清晰度）放在**各自效果页**里，方便对照。
- 影响整个画面的清晰与流畅（抗锯齿、超分、渲染缩放）放在「清晰与流畅」页。
- 同一个参数**只出现一次**，不允许在两个页面重复出现。

## 预设

主界面的 `预设` 按钮提供成套设置，例如：省电、流畅、均衡、写实、电影、氛围。
预设只改数值，不换算法。切换预设不会丢失未覆盖的参数（未覆盖的按源码默认）。

## 自检规则（重写时必须实现）

1. 每个参数必须恰好出现在一个页面，**出现零次或两次都构建失败**。
2. 菜单里出现的选项，必须能在效果源码里找到定义，否则失败。
3. 效果源码里定义的选项，必须出现在菜单里，否则失败。
4. 生成的中文说明必须能通过审计（有效中文、无裸英文）。

## 实施顺序

1. 按 `parameters.md` 把现有参数改名、去掉算法选择、补齐「清晰与流畅」等新页。
2. 改菜单生成器，支持主界面/多级子页/栏数/数值标签/悬停说明。
3. 加自检规则 1–3。
4. 按 `parameters.md` 的「缺失」列逐个实现新参数与新效果。
