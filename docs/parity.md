# 与 iterationT 的能力对照与补齐计划

参考对象：`references/iterationT`（iterationT 3.2.0）。本文件只做能力与选项的对照，
不复制参考实现的源码；算法按公开资料独立实现，来源记入 `docs/libraries.md`。

## 现状

- iterationT 3.2.0 的菜单选项：268 个（`lang/en_us.lang` 里 `option.` 键）。
- Omni 当前：165 个（构建输出「检查通过」里的选项数）。
- 目标：选项数量不少于 iterationT，且每一项都接到真实计算，不做占位。

## 执行顺序

1. 天空与大气（最影响第一眼观感）。
2. 光照与阴影（决定立体感与真实感）。
3. 云与天气（天空与地面衔接）。
4. 水（近景质感）。
5. 后处理（曝光、锐化、景深、模糊）。
6. 间接光（GTAO 与屏幕空间全局光）。
7. 材质与视差。
8. 世界与远景、开发者。

每一步都：实现算计的算法 → 加选项 → 生成 → 离线检查 → 实机截图核对 → 提交推送。
每个小步保证选项只增不减。
