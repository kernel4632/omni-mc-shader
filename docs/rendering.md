# 绘制流程

本版有完整代码接线，只有离线验证。Minecraft 世界画面与效果顺序仍需实机确认。

```text
shadow                         → shadowtex0
dh_terrain / gbuffers_*         → 0、1、2、7 与各自深度
deferred                       → 0、3（不透明快照与自定义天空）
dh_water / gbuffers_water       → 0、7、8（玻璃拒绝几何匹配，水保存自身深度）
无可靠深度的透明与覆盖程序       → 0、7（保留底层法线和类别，只标记匹配无效）
composite                      → 6（水、反射、遮蔽、间接光、云、雾、闪电）
composite1                     → 0、4、5（抗锯齿、历史、曝光）
final                          → 屏幕（镜头、泛光、调色、显示编码、调试）
```

入口由 `rendering/programs.json` 显式列出。Iris 当前文档说明：任意 `worldN` 存在时只从维度目录加载，所以实际入口同时放在 `world0`、`world-1`、`world1`；根目录只保留共用代码，不放可执行入口。共 30 个程序、90 组顶点片元、180 个入口文件。入口只声明 GLSL 330 compatibility、阶段宏、维度宏和主体引用；所有编号与格式来源是 `rendering/buffers.glsl`。

| 附件 | 格式与通道 | 写入者 → 读取者 |
| --- | --- | --- |
| 0 | RGBA16F，线性照明 RGB；几何阶段 A 为颜色透明度，时间阶段 A 为历史连续且几何有效标志 | 几何 → 延迟快照、合成；时间合成 → 最终显示与运动模糊 |
| 1 | RGBA16F，视空间法线×0.5+0.5，A 类别：0 普通、2 手、3 DH；透明阶段不改底层类别 | 不透明几何 → 合成、时间与调试 |
| 2 | RGBA16F，线性粗糙度、labPBR 反射编码、自发光、天空光 | 几何 → 反射、天气、调试 |
| 3 | RGBA16F，不透明线性照明与天空 RGB | deferred → 水折射、SSR、屏幕反弹 |
| 4 | RGBA16F，上一帧线性 RGB、有效 A；不清除 | composite1 → 下一帧时间合成 |
| 5 | RGBA32F，米制距离、曝光、帧号、维度；不清除 | composite1 → 下一帧历史判断与最终曝光 |
| 6 | RGBA16F，时间处理前的合成线性颜色 | composite → composite1 |
| 7 | RGBA16F，方块光、天空光、水来源（0 无、1 近景、2 DH）、几何匹配有效标志 | 几何与覆盖层 → 合成、时间、镜头与调试 |
| 8 | RGBA32F，水面视空间法线编码 RGB、真实视空间 Z（负数）；无水为零 | 近远水几何 → 重建、合成与镜头；每帧清除 |

附件 5 的 `(0,0)` 像素例外保存宽、高、维度、帧号；`(1,0)` 保存绝对相机位置与帧号。时间合成拒绝这两个像素的深度读取。最终曝光从画面中心读，避免元数据混用。维度签名为主世界 1、下界 2、末地 3。尺寸、连续帧号、维度、相机跳变、重投影边界、深度差、手持类别和当前颜色邻域共同控制历史有效性。天空不累积，动态实体没有独立速度，只做保守拒绝。

最终镜头不再检查已经翻转为本帧的附件 5。时间合成在写入前计算旧历史有效性，作为附件 0 A 传给最终镜头；运动模糊用当前真实深度与两帧相机矩阵计算位移，拒绝八米以上跳变、负投影 W 和屏幕外位置，速度同时撤销当前与历史抖动。透明叠层、手和天空不做相机模糊。

贴图 RGB 在几何阶段按标准 sRGB 公式转换为线性；材质、深度、法线不做颜色转换。光照、透明混合、反射、雾、时间合成、泛光和镜头在线性空间完成。最终 tone map 后才转回显示 sRGB。原版环境色按颜色输入处理，不当作材质数据。

`depthtex0` 是最近场景深度，`depthtex1` 是不透明深度。DH 的 `dhDepthTex0/1` 使用独立的 `dhProjectionInverse`，不能按普通深度解释。近景深度空白时才选择远景；TAA 使用对应 `dhPreviousProjection`。远景入口只读官方支持的顶点色、法线、光照坐标和自动 `dhMaterialId`，不读取普通图集，不承诺远景 PBR 或远景阴影。`dhShadow.enabled=false` 明确关闭该独立远景阴影路径。

透明颜色保留加载器混合。基础线条、粒子、天气、方块破坏、附魔、眼部发光、半透明实体与手仅输出颜色和附件 7 的无效标志；不会覆盖附件 1／2 的底层类别与材质。Iris 可选 `ENTITY_TRANSLUCENT` 和粒子混合排序显式接入；不支持实体分离的加载器把整类实体保守作为覆盖层。不依赖任何程序名来猜测深度写入。

水独立记录法线与插值视空间 Z，近远景各用自己的逆投影视线重建，水都以颜色 A=1 读取不透明快照。完全透明 DH 片元丢弃。玻璃保持原生透明并清除水记录；混合透明叠层明确拒绝全像素 SSAO、SSR、雾与 TAA，避免用底层地形／手深度解释顶层颜色。本版不是顺序无关透明，没有完整多层介质分离。

SSR 不再使用近景 UV 解释 DH 深度。每个步进点分别使用 `gbufferProjection`／`depthtex1` 与 `dhProjection`／`dhDepthTex1` 成对比较，再在对应命中 UV 读取快照；DH 命中若该 UV 已被近景颜色覆盖则拒绝。

`pipeline.properties` 控制独立阴影程序关闭、原版云与天体关闭、透明元数据混合。选项仍在效果文件单独定义。关闭无独立程序的算法通过编译分支或常量折叠移除采样；缓冲由多项能力共用，未声称关闭单个效果会释放附件或显存。
