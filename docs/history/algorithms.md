# 算法对照：iterationT 3.2.0

本文件记录 iterationT 做了哪些计算、Omni 的对应文件、以及还缺哪些选项。
只对齐算法与选项，不复制参考源码；公式与常数取自公开资料，来源见 `docs/libraries.md`。

## iterationT 的组织（供对照，不照搬）

- `Lib/Settings.glsl`：材质编号与选项定义（253 个 define，其中 180 个带取值或开关）。
- `Lib/BasicFounctions/`：大气散射、日照与阴影、时间抗锯齿、方块光、下界配色、时序噪声、原版合成。
- `Lib/IndividualFounctions/`：AgX、泛光、云影、景深、末地天空、FSR、全局光、GTAO、镜头眩光、运动模糊、体积云、视差、海面、平面云、涟漪、水下体积雾、体积雾、水波、SSR、反射滤波。
- 绘制程序为根目录加 `world-1`、`world1`，16 个 composite、6 个 deferred。

## 大气模型常数（Bruneton 预计算散射模型，公开论文）

- 太阳辐照度 `(1.68194, 1.85149, 1.91198)`，太阳角半径 `0.005`。
- 大气底半径 `6360`，顶半径 `6420`（公里）。
- 瑞利散射 `(0.008396, 0.014590, 0.033100)`。
- 米氏散射 `0.003996`，米氏消光 `0.004440`，米氏各向异性 `g = 0.8`。
- 臭氧吸收 `(0.0020031, 0.0016555, 0.0000847)`，地面反照率 `0.1`。
- 高度剖面：瑞利约八公里、米氏约一点二公里、臭氧集中在约二十五公里。

## 执行顺序

天空与大气 → 光照与阴影 → 云与天气 → 水 → 后处理 → 间接光 → 材质与视差 → 世界与远景。
每一步：按上面常数与模型实现 → 加选项 → 离线检查 → 实机截图核对 → 提交。选项只增不减。
