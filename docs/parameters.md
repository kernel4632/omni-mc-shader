# 参数总表

本文件是菜单与参数的唯一规划清单。重写后，菜单、生成器和构建自检都以它为准。
菜单的显示名与代码里的标识符分开：标识符用英文（`OMNI_` 前缀），显示名用中文（写在 `.lang` 里）。
这样改显示名不动标识符，旧配置还能继续用。

## 列说明

- 标识符：代码与配置里的名字。已存在的沿用，避免破坏旧配置；标「新」的是待新增。
- 菜单中文名：玩家在菜单里看到的词。
- 主分类 / 子页：菜单归属。
- 类型：开关 / 数值 / 档位（几个直观档，不给算法名）。
- 档位或范围：可选值或滑条范围。
- 改什么：拖一下画面会发生什么，只用 Minecraft 的话说。
- 状态：已有 / 需改（现有但要去算法化或改显示名）/ 缺失 / 去掉（算法选择，改为内部固定）。

## 内部接口（不做成玩家参数）

下面这些是 Iris 允许控制、但**不给玩家选项**，由项目内部固定，避免玩家被专业设置困扰：

- 各效果用哪种算法（云做法、遮蔽做法、高光压缩做法、抗锯齿做法）。
- 缓冲的格式、数量、清除颜色、mipmap。
- 阴影贴图 FOV、间隔、硬件过滤。
- 计算着色器的工作组尺寸、自定义图像布局。
- 平台能力检测与自动降级（缺计算能力、缺实体分离时自动回退）。
- 颜色空间、纹理过滤模式。

## 覆盖规则

1. `parameters.md` 里的每个参数，最终都必须在效果源码里有一个定义，并且在菜单里出现一次。
2. Iris 允许控制、但本表标为「内部接口」的东西，不进菜单，也不需要玩家理解。
3. 新增能力时，先在 `parameters.md` 登记，再实现；不在表里的参数不许直接进代码。

- 玩家可调参数：约 180 条（含标「新」「缺失」「需改」）。
- 其中已实现：约 100 条；需改显示名或去算法化：约 8 条；去掉的算法选择：4 条；新参数：约 40 条；缺失效果参数：约 30 条。
